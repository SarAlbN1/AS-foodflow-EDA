# Pruebas ejecutadas

[← Implementación](../estructura-del-repositorio.md) · [Índice de la wiki](../../Home.md)

Registro de las mediciones que respaldan lo que afirma la arquitectura. Cada
página anota **fecha, entorno y valores medidos**, para que el resultado se
pueda repetir y comparar.

| Página | Qué registra | HU |
|---|---|---|
| [Atributos de calidad medidos](atributos-de-calidad.md) | Una medición por criterio de la página [Atributos de calidad verificables](../../02-arquitectura/atributos-de-calidad.md), con el comando que la reproduce | HU-608 |

Las pruebas unitarias y de integración de cada servicio no se registran aquí:
se ejecutan con `./mvnw verify` y su resultado vive en el PR de cada HU.
